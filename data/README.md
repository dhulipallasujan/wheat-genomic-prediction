# Local input data

For local analysis, place these four files in this folder:

- `GenoInfo.csv`
- `PhenoInfo_TPE1.csv`
- `PhenoInfo_TPE2.csv`
- `PhenoInfo_TPE3.csv`

They are available from the [source repository](https://github.com/guillermogarci4/MultiEnv-Wheat-Genomic-Prediction). That repository does not display a data license, so confirm its reuse terms before sharing or redistributing the files. The project `.gitignore` excludes CSVs in this folder to prevent accidentally adding the raw data to GitHub.
